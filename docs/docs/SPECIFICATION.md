# Pokébox

## Objetivo

Gerenciar Pokémon, itens e saves de jogos Pokémon em um único aplicativo Android.

## Jogos suportados

- FireRed
- LeafGreen
- Ruby
- Sapphire
- Emerald

## Recursos

- Vault de Pokémon
- Vault de Itens
- Backup de Saves
- Transferência entre Saves
- Histórico de transferências
